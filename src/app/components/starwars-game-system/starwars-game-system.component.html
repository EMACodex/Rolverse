Qué es el sistema de juego de Star Wars

Star Wars ha tenido varias líneas de rol de mesa, cada una con una forma distinta de representar aventuras galácticas. Algunas se centran en dados de seis caras y acción cinematográfica rápida, otras usan reglas d20 cercanas a Dungeons & Dragons, y las más modernas emplean dados narrativos para mezclar éxito, amenaza, ventaja, complicaciones y drama en una misma tirada.

Cómo evolucionó el sistema

Primero llegó la etapa de West End Games con el sistema D6, muy ágil y cinematográfico. Después Wizards of the Coast publicó las versiones d20 y Saga Edition. Más tarde Fantasy Flight Games y Edge Studio desarrollaron una línea narrativa dividida en contrabandistas, rebeldes y usuarios de la Fuerza.

Qué versión elegir para jugar

Si quieres rapidez clásica, WEG D6 funciona muy bien. Si prefieres algo parecido a D&D, d20 o Saga son más familiares. Si buscas partidas narrativas con consecuencias, tensión cinematográfica y mucha improvisación, la línea FFG / Edge Studio es la opción más moderna.
