# Rolverse App Builds

Rolverse uses the same Angular frontend for web, desktop, and mobile builds. The backend is not bundled into Electron or Capacitor, and no API keys or secrets are included in Angular, Electron, or Capacitor.

## API URLs

Development builds use:

`http://localhost:3000`

Production builds use:

`https://rolverseproyecto.onrender.com`

The backend must be available at that production URL for login, register, forum, news, matches, chatbot, and user features to work in packaged apps.

## Web

Development:

```bash
npm start
# or
ng serve
```

Production build:

```bash
ng build --configuration production
```

## Electron Desktop App

Development with Angular dev server:

```bash
npm run electron:dev
```

Local packaged-style test with the local backend:

```bash
npm run electron:start:local
```

This uses:

`http://localhost:3000`

Local installer for testing only:

```bash
npm run electron:build:local
```

Do not publish this installer, because it points to `localhost:3000`.

Production run from the Angular production build:

```bash
npm run electron:start
```

Production installer/package:

```bash
npm run electron:build
```

This uses:

`https://rolverseproyecto.onrender.com`

The desktop app uses `electron/main.js` and loads `http://localhost:4200` in development. In production it loads `dist/rolverse/browser/index.html`. The backend is external.

For Windows installer icons, Electron Builder may require a dedicated `.ico` file generated from `src/assets/img/app.png`.

## Capacitor Mobile App

Sync mobile project after a production build:

```bash
npm run cap:build
```

Open Android Studio:

```bash
npm run cap:android
```

This uses:

`https://rolverseproyecto.onrender.com`

For Android emulator tests against the local backend, an `android-local` build configuration is available:

```bash
npm run cap:android:local
```

This uses:

`http://10.0.2.2:3000`

Do not use the Android local build for production.

Android requires Android Studio installed. iOS requires macOS and Xcode; add iOS on a Mac with:

```bash
npm install @capacitor/ios
npx cap add ios
```

Mobile native icons should be generated from:

`src/assets/img/appmovil.png`

Command prepared in package scripts:

```bash
npm run cap:assets
```
## Footer Download Files

The footer download links expect these files:

```text
src/assets/downloads/rolverse-desktop.exe
src/assets/downloads/rolverse-mobile.apk
```

After building Electron, copy the generated Windows installer from `release/` to:

```text
src/assets/downloads/rolverse-desktop.exe
```

Use the installer generated by `npm run electron:build` for the production download. Do not use `npm run electron:build:local` for the public download.

After building the Android APK, copy the final APK to:

```text
src/assets/downloads/rolverse-mobile.apk
```

For testing, a debug APK can be used. For distribution, use a signed release APK.
